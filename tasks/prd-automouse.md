# PRD: AutoMouse 鼠标键盘自动操作工具

## 1. 概述

AutoMouse 是一款 Windows 桌面端的鼠标键盘操作录制与回放工具。用户可以录制自己的鼠标移动、点击、滚轮、拖拽及键盘按键操作，然后精确回放这些操作，支持循环执行。适用于办公自动化、软件测试和游戏辅助等重复性操作场景。

## 2. 目标

- 提供全局鼠标键盘操作录制功能，精确捕获所有输入事件
- 支持原速回放和循环回放，按录制时间间隔精确重放
- 提供全局热键控制录制和回放的启停，无需切换窗口
- 支持录制后编辑操作步骤（删除、插入、修改）
- 提供多脚本管理，JSON 格式存储，可保存和加载多个录制脚本
- 系统托盘常驻，操作时窗口可隐藏

## 3. 用户故事

### US-001: 安装全局键鼠钩子
**描述：** 作为用户，我希望工具能在系统全局捕获鼠标和键盘事件，这样我可以录制任何应用中的操作。

**验收标准：**
- [ ] 使用 WH_MOUSE_LL 和 WH_KEYBOARD_LL 安装低级钩子
- [ ] 钩子能捕获所有应用中的鼠标和键盘事件
- [ ] 提供 Start()/Stop() 接口控制录制启停
- [ ] 停止录制时返回完整的事件列表

### US-002: 录制鼠标事件
**描述：** 作为用户，我希望录制鼠标的移动、点击、滚轮和拖拽操作，这样我能捕捉完整的鼠标交互。

**验收标准：**
- [ ] 记录鼠标移动事件（坐标 X/Y + 时间戳）
- [ ] 记录鼠标按下/抬起事件（左键/右键/中键 + 坐标 + 时间戳）
- [ ] 记录滚轮滚动事件（Delta + 坐标 + 时间戳）
- [ ] 拖拽操作由 down → move → up 序列自然组成，无需特殊处理
- [ ] 所有事件时间戳为相对录制开始的毫秒数

### US-003: 录制键盘事件
**描述：** 作为用户，我希望录制键盘按键操作包括组合键，这样我能录制快捷键操作。

**验收标准：**
- [ ] 记录按键按下/抬起事件（虚拟键码 + 时间戳）
- [ ] 记录修饰键状态（Ctrl/Alt/Shift/Win）
- [ ] 组合键以可读字符串存储（如 "Ctrl+C"）
- [ ] 支持所有标准键盘按键

### US-004: 回放操作序列
**描述：** 作为用户，我希望精确回放录制的操作序列，这样我能自动重复执行任务。

**验收标准：**
- [ ] 使用 SendInput Win32 API 模拟鼠标和键盘操作
- [ ] 按录制时的时间间隔精确调度每个事件
- [ ] 回放在独立线程执行，不阻塞 UI
- [ ] 支持 CancellationToken 随时中断回放
- [ ] 回放过程中监听停止热键

### US-005: 循环回放
**描述：** 作为用户，我希望设置循环次数来重复执行操作序列，这样我能批量处理任务。

**验收标准：**
- [ ] 可设置循环次数（1~N）
- [ ] 可设置无限循环
- [ ] 界面实时显示当前循环进度（如 2/5）
- [ ] 循环间可配置间隔时间

### US-006: 全局热键控制
**描述：** 作为用户，我希望通过热键控制录制和回放的启停，这样我在操作其他应用时也能控制工具。

**验收标准：**
- [ ] 使用 RegisterHotKey 注册全局热键
- [ ] 默认热键：F9 开始录制 | F10 停止录制 | F7 开始回放 | F8 停止回放
- [ ] 热键可在设置中自定义
- [ ] 通过 HwndSource.AddHook 在 WPF 中接收 WM_HOTKEY 消息

### US-007: 步骤编辑
**描述：** 作为用户，我希望录制后能编辑操作步骤，这样我能修正或优化录制结果。

**验收标准：**
- [ ] 用 DataGrid 展示事件列表（序号/类型/动作/坐标/按键/延迟）
- [ ] 支持选中行删除
- [ ] 支持修改单步属性（坐标、按键、延迟时间）
- [ ] 支持插入新步骤
- [ ] 支持上移/下移调整步骤顺序
- [ ] 编辑后可保存更新脚本

### US-008: 脚本保存与加载
**描述：** 作为用户，我希望保存录制的脚本并能随时加载，这样我可以重复使用。

**验收标准：**
- [ ] 脚本以 JSON 格式存储
- [ ] 存储路径：%APPDATA%/AutoMouse/scripts/
- [ ] 保存时包含元数据（名称、创建时间、总时长）
- [ ] 可加载已保存的脚本进行回放或编辑

### US-009: 多脚本管理
**描述：** 作为用户，我希望管理多个脚本，这样我可以为不同任务维护不同的操作序列。

**验收标准：**
- [ ] 脚本列表展示所有已保存脚本（名称、事件数、时长）
- [ ] 支持加载选中脚本
- [ ] 支持重命名脚本
- [ ] 支持删除脚本

**验收标准：**
- [ ] 窗口可最小化到系统托盘
- [ ] 托盘图标右键菜单（开始录制/开始回放/显示窗口/退出）
- [ ] 录制时可自动隐藏窗口（可配置）

**描述：** 作为用户，我希望看到录制的实时状态，这样我能了解录制进度。

**验收标准：**
- [ ] 显示录制时长（秒.毫秒格式）
- [ ] 显示已捕获事件数
- [ ] 显示当前状态（待机/录制中/回放中）
- [ ] 回放时显示当前进度（第 N 步/共 M 步，循环 i/n）

## 4. 功能需求

- FR-1: 系统通过 WH_MOUSE_LL 和 WH_KEYBOARD_LL 低级钩子全局捕获鼠标和键盘事件
- FR-2: 每个事件记录类型、动作、坐标/按键、相对时间戳
- FR-3: 录制开始时启动计时器，所有事件时间戳为相对录制开始的毫秒数
- FR-4: 回放引擎通过 SendInput API 按 Timestamp 调度事件，保持原始时间间隔
- FR-5: 回放支持设置循环次数（0 = 无限循环）
- FR-6: 回放在独立线程执行，通过 CancellationToken 可随时中断
- FR-7: 全局热键注册通过 RegisterHotKey，默认 F9/F10/F7/F8，可自定义
- FR-8: 脚本以 JSON 格式存储到 %APPDATA%/AutoMouse/scripts/ 目录
- FR-9: 脚本管理支持保存、加载、删除、重命名、列表查看
- FR-10: 编辑面板用 DataGrid 展示事件，支持增删改和排序
- FR-11: 窗口支持最小化到系统托盘，托盘菜单提供快速操作
- FR-12: 录制中可配置自动隐藏窗口
- FR-13: 状态栏实时显示录制时长、事件计数、当前状态
- FR-14: 回放进度实时显示（当前步骤/总步骤，当前循环/总循环）

## 5. 非目标（不在范围内）

- 不支持变速回放（如 2x、5x 倍速）
- 不支持脚本导入/导出（文件级分享）
- 不支持条件分支和循环逻辑（如 if/while 脚本编程）
- 不支持跨平台（仅 Windows）
- 不支持图像识别和找图点击
- 不支持录屏（视频录制）
- 不支持网络远程控制
- 不支持多显示器独立录制

## 6. 设计考虑

- UI 采用单窗口多 Tab 页布局（录制/回放/编辑/脚本管理/设置）
- 使用 CommunityToolkit.Mvvm 实现 MVVM 模式，减少样板代码
- Win32 API 调用集中在 Utils/Win32/ 目录，不散落在业务代码中
- DataGrid 展示事件列表，支持行选中编辑
- 系统托盘使用 NotifyIcon 实现
- 主题风格：简洁实用，深色/浅色可选

## 7. 技术考虑

- **框架：** .NET 8 + WPF
- **MVVM：** CommunityToolkit.Mvvm（ObservableObject, RelayCommand）
- **序列化：** System.Text.Json（驼峰命名 + 缩进美化）
- **全局钩子：** SetWindowsHookEx / UnhookWindowsHookEx（WH_MOUSE_LL, WH_KEYBOARD_LL）
- **输入模拟：** SendInput API（INPUT_MOUSE, INPUT_KEYBOARD）
- **热键：** RegisterHotKey / UnregisterHotKey + HwndSource.AddHook
- **线程：** 回放使用 Task + CancellationToken，钩子回调在 UI 线程消息循环
- **性能：** 录制时事件写入内存 List，停止时批量处理，避免 IO 阻塞

## 8. 成功指标

- 录制的事件回放后能在目标应用中准确重现原操作
- 录制 1000 个事件的内存占用低于 5MB
- 回放延迟精度在 ±10ms 以内
- 热键响应时间在 100ms 以内
- 脚本加载/保存时间在 500ms 以内（1000 事件）
