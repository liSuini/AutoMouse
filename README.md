# AutoMouse - 鼠标键盘自动操作工具

一款 Windows 桌面端的鼠标、键盘操作录制与回放工具。

## 核心功能

- **录制**：捕获鼠标移动、点击、滚轮滚动及键盘按键操作，记录时间戳与坐标
- **回放**：按录制的时间序列精确重放所有操作，支持循环执行
- **编辑**：查看、修改、删除已录制的操作步骤
- **脚本管理**：保存/加载录制脚本，支持多脚本管理
