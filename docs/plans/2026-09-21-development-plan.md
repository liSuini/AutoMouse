## 风险管理

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| 低级钩子被系统超时移除 | 低 | 录制中断 | 回调处理 < 5ms，异常时自动重装 |
| SendInput 被游戏反作弊拦截 | 中 | 游戏场景不可用 | 文档说明限制，不作为 bug |
| 移动事件过多导致 JSON 过大 | 中 | 内存/磁盘压力 | 采样降稠密 + 最大事件数限制 |
| 无 C# IDE 开发效率低 | 中 | 开发变慢 | 使用 dotnet CLI + VS Code |
